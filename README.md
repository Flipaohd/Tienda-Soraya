# Soraya Perfumes y Cosméticos 🌸

Tienda online de perfumería, cosmética y moda. Desde 1991.

## Archivos

|Archivo      |Descripción                                       |
|-------------|--------------------------------------------------|
|`index.html` |**Web pública** — lo que ven tus clientes         |
|`Gestor.html`|**Panel de administración** — gestión de productos|

## Cómo publicar en GitHub Pages

1. Crea un repositorio en [github.com](https://github.com)
1. Sube los archivos `index.html` y `Gestor.html`
1. Ve a **Settings → Pages → Source: main branch**
1. Tu web estará en: `https://TU-USUARIO.github.io/NOMBRE-REPO/`

## Panel de Administración (Gestor.html)

- **Acceso:** Email y contraseña privados
- **Credenciales por defecto:** `admin@soraya.es` / `Soraya1991`
- **Cambia la contraseña** en Configuración → Cambiar Contraseña
- Añade, edita y elimina productos con fotos
- Genera el `index.html` actualizado y súbelo a GitHub
